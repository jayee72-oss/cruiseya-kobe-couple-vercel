# Contributing

Thank you for your interest in improving Cruise Landing Page Starter.

This project is evolving from a real-world cruise landing page into a reusable open-source starter for travel landing pages. Contributions that improve reuse, accessibility, documentation, testing, maintainability, and travel-specific components are especially welcome.

## Ways to contribute

You can help by:

- reporting reproducible bugs
- improving documentation
- suggesting reusable travel or cruise components
- improving accessibility and responsive behavior
- adding or improving tests
- simplifying configuration for non-developers
- proposing AI-assisted maintainer workflows that are transparent and reproducible

## Before opening a pull request

1. Fork or branch from the latest `main` branch.
2. Keep changes focused on one problem or improvement.
3. Do not include API keys, credentials, customer information, or other secrets.
4. Run the relevant checks locally.

```bash
npm install
npm run build
npm test
```

If your change affects user-facing behavior, describe what changed and how you verified it.

## Pull requests

A useful pull request should include:

- a clear title
- the problem being solved
- a short explanation of the approach
- screenshots for meaningful visual changes when appropriate
- testing or verification notes

Small, focused pull requests are preferred over large unrelated changes.

## Issues and feature ideas

When reporting a bug, include the expected behavior, actual behavior, reproduction steps, and environment details when relevant.

For feature ideas, explain the travel-business or maintainer problem the feature would solve. The project prioritizes reusable capabilities over one-off campaign-specific customizations.

## AI-assisted contributions

AI-assisted coding is welcome. Contributors remain responsible for reviewing generated code, verifying behavior, respecting licenses, and avoiding the inclusion of sensitive information. If AI materially shaped a complex change, a short note in the pull request about how it was verified is encouraged.

## Code of conduct

Be respectful, constructive, and focused on improving the project. Harassment, personal attacks, and discriminatory behavior are not acceptable.
